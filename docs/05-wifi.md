# Wi-Fi: WAV654, драйверы, калибровка

## Что за железо

Archer AX50 несёт два радиомодуля **MaxLinear (ранее Intel) WAV654**, семейство
**WAV600 gen6**: 2×2 в 2.4 ГГц и 2×2 в 5 ГГц, 802.11ax. Подключены по PCIe
(в DTB три контроллера `lantiq,pcie-xrx500`).

## Два драйвера — один код

| | стоковая прошивка | наша сборка |
|---|---|---|
| модуль | `mtlk.ko` (+`mtlkroot.ko`), бинарь от TP-Link | `iwlwav` из исходников |
| версия | `06.00.08.00.87.00.07.d24084bd3447` | ветка `ugw-8.4.1-cleanup` |
| ядро | 3.10.104 | 4.9.206 |
| hostapd | `/opt/lantiq/bin/hostapd` (вендорский форк) | `iwlwav-hostap-uci` |
| исходники | закрыты в поставке (см. ниже) | [gitlab.com/prpl-foundation/intel/iwlwav-dev](https://gitlab.com/prpl-foundation/intel/iwlwav-dev) |

Это один и тот же драйвер в разных ипостасях. Внутри `mtlk.ko` видны пути сборки
вида `.../wireless/driver/linux/cfg80211.c` — драйвер работает через **cfg80211**,
как и открытый `iwlwav`. Поэтому «поставить бинарный `mtlk.ko` от TP-Link в свою
сборку» — тупиковый путь: модуль намертво привязан к ядру 3.10.104 из вендорского
SDK (vermagic, ABI). Правильный путь — собирать `iwlwav` под своё ядро, что и делает
профиль сборки.

### Про исходники в GPL TP-Link

В архиве `ax50v1_GPL_3.tar.gz` действительно лежит
`dl/lq-wave-300-06.00.08.00.87.00.07.d24084bd3447.gpl.wls.src.tar.bz2` (1109 файлов) —
это исходник ровно той версии драйвера, что в прошивке. **Но** рецепт сборки
(`feeds_ugw/wlan/wlan_wave_feed_6x/lq-wave-300_6x/Makefile`) из архива вырезан:
в `feeds/ugw_packages.tmp/info/` остались только метаданные пакета, а сам каталог
фида отсутствует. Восстанавливать этот фид ради ядра 3.10 смысла нет —
в prpl лежит тот же код с готовой обвязкой под 4.9.

## Прошивки радио

Пакет `wave_bin` / `ltq-wlan-wave_6x-uci` приносит то же, что лежит в стоке
в `/lib/firmware`:

- `ap_ram_gen6_wrx_600_real_phy.bin` — основной firmware радио (1.5 МБ)
- `ProgModel_gen6_Common.bin`, `ProgModel_gen6_Ant_Tx/Rx.bin` — модели PHY
- `host_interface_gen6*.bin`, `rx_handler_gen6*.bin`, `tx_sender_gen6*` — микрокод трактов
- `PSD.bin`

## Калибровка и MAC-адреса — самое важное

Калибровка радио и заводские MAC-адреса лежат в MTD-разделе **`calibration`**
(`0x1C0000`, 1 МиБ). Она **уникальна для каждого экземпляра** и не восстанавливается
ниоткуда: ни из прошивки TP-Link, ни от другого роутера.

- никогда не стирайте и не перезаписывайте этот раздел;
- снимите его дамп до любых экспериментов (`scripts/backup-router.sh`);
- в стоке есть «дефолтные» файлы `/lib/wifi/default_cal_wlan0*.bin` — это не ваша
  калибровка, а заводская заглушка; с ней радио работает вне параметров.

Как именно `iwlwav` в сборке prplWrt читает калибровку из `calibration` для AX50 —
**открытый вопрос**, требующий проверки на устройстве: у референс-плат путь получения
EEPROM может отличаться. Это задача №2 в [`06-roadmap.md`](06-roadmap.md).

## Настройка после запуска

Wi-Fi в этом BSP управляется не стандартным `wifi-device`/`mac80211`, а связкой
`ltq-wlan-wave_6x-uci` + `iwlwav-hostap-uci` + `dwpal`/`swpal`. Конфигурация — через
UCI, но набор опций свой. Смотрите `/etc/config/wireless` после первой загрузки и
скрипты из пакета `iwlwav-base-files`.

Диагностика:

```sh
lsmod | grep -i wav          # драйвер загрузился
dmesg | grep -i -E 'wav|wlan|iwlwav'
iw dev                       # интерфейсы wlan0/wlan2
logread | grep hostapd
```
